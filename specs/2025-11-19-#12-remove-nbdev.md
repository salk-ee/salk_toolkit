# Retire the nbdev notebook workflow (PR #12)

**Modules:** `salk_toolkit/*.py`, `nbs/` (deleted), `pyproject.toml`, `.pre-commit-config.yaml`,
`Makefile`, `README.md`

## Goal

`salk_toolkit` was maintained as nbdev notebooks under `nbs/` that exported to the `.py`
modules, so every module had two sources of truth and every diff carried cell noise. Nobody
actually ran the package notebooks, and coding agents handle `.ipynb` badly. This PR makes
the `.py` modules canonical, moves the narrative documentation out of markdown cells into
docstrings, and replaces the nbdev toolchain with plain setuptools + ruff + pdoc.

## Design

- **Modules become the source.** `io`, `pp`, `plots`, `dashboard`, `election_models`,
  `commands`, `utils` and `validation` lose their `# AUTOGENERATED` banners and
  `# %% ../nbs/...` cell markers. Each notebook's first markdown heading becomes the module
  docstring; the intermediate explanatory cells become section banner comments:
  ```
  # --------------------------------------------------------
  #          PLOT REGISTRATION
  # --------------------------------------------------------
  ```
  The runtime API is untouched — same `__all__`, same top-level names, same plot-registry
  population order.

- **nbdev artifacts deleted:** all of `nbs/` (`01_io` … `11_commands`, `index.ipynb`,
  `nbdev.yml`, `_quarto.yml`, `sidebar.yml`, `styles.css`), the generated `_docs/` site, and
  `salk_toolkit/_modidx.py`. `index.ipynb`'s content becomes `README.md`; root
  `examples.ipynb` survives as standalone examples. Data files that lived under `nbs/` are
  triaged to `tests/data/` (fixtures) or `examples/`.

- **Packaging:** `settings.ini` and `setup.py` are deleted. All metadata — version, authors,
  dependencies, keywords, and the `[project.scripts]` entry points `stk_explorer` and
  `stk_translate_dashboard` — moves into `pyproject.toml` on a setuptools backend. The
  version lives only there; it is removed from `__init__.py`.

- **Docs:** Google-style docstrings, declared by `[tool.pdoc] docformat = "google"` and
  rendered by pdoc. `make docs` and a pre-commit hook both run
  `pdoc --output-directory docs_html salk_toolkit !salk_toolkit.tools.explorer`. `docs_html/`
  is a CI artifact, not committed.

- **Pre-commit** loses the `export-notebooks` and `nbdev_docs` hooks and gains ruff
  (`--fix --unsafe-fixes`), ruff-format, autopep8 (trailing-whitespace rules only), pytest
  and pdoc — all running directly against `.py` files, with `.ipynb` excluded.

- **Lint scope is deliberately narrow.** Ruff selects `E`/`F`/`W` at line-length 120 but
  ignores the ten families that cannot be auto-fixed (`F403`, `F405`, `F821`, `E741`, `F401`,
  `F811`, `E402`, `E501`, `E721`, `E722`), keeping this migration mechanical. PR #14 clears
  that ignore list.

## Implementation notes

- Explorer is excluded from doc builds (`!salk_toolkit.tools.explorer`) and guards its
  `localStorage`/CLI access, because pdoc imports modules and the Streamlit app executes at
  import time.
- The `.cursor/rules/*` files and the older specs that instructed "edit the notebook, export
  the py" are rewritten in the same PR — otherwise the migration is undone by the next
  contributor following the rules.
